# M4b, part 2 — Page width, code, maths, diagrams, outline, text files: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pages get full width at three levels (app, vault, page). Code blocks are highlighted, with a language picker and Copy. `$…$` and `$$…$$` render with KaTeX, and ```` ```mermaid ```` fences render as diagrams. An outline panel and a word count join the header band. Plain-text and code files open in a text view.

**Architecture:**
- **Rust:**
  - widths live in `.nimw/vault.json` (`nimw-vault::page_width`, remapped with the M3a layout on renames);
  - `settings.json` gains `pageWidth` and `outline`;
  - text files get `text_read`/`text_write` (`nimw-session::text_files`), with the page commands' compare-and-swap, indexed as attachments.
- **Parsed model:**
  - maths comes from `remark-math` in `parsePage`;
  - code is highlighted by `lowlight` before sanitizing, and by `@codemirror/language-data` in the editor, both drawing with `--code-*` tokens generated per palette.
- **Lazy loading:** KaTeX renders into placeholders. Mermaid loads lazily on first use.
- **Outline and word count:** both read an incrementally re-parsed model (`pageModel.parsedFor`) and follow the editor through `viewUpdates`.
- **Frozen prototypes:** `freezeSafe` becomes a general, AST-based Vite transform, so Mermaid's whole dependency tree loads under Tauri's frozen `Object.prototype`.

**Tech Stack:**
- React 19 + TS, CodeMirror 6, zustand, unified/remark;
- Vitest (jsdom), Playwright (Chromium + WebKit);
- Rust (`nimw-vault`, `nimw-session`, `nimw-markdown`, Tauri commands).
- **New dependencies (exact):**
  - `@codemirror/language-data@6.5.2`
  - `lowlight@3.3.0`
  - `remark-math@6.0.0`
  - `katex@0.18.9`
  - `mermaid@11.17.2`

// obj.name = v  →  __nimwOwn(obj, "name").name = v   (any node_modules file)
// Object.assign →  __nimwAssign                        (not where it is assigned)
var __nimwOwn=function(o,k){ /* own writable, enumerable prop, only when the

}

    Ok(hash)
