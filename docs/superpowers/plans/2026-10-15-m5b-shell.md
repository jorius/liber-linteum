# M5b Stream A — Shell overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the top bar with menus, a vault menu, a floating action button and a collapsible sidebar. Put the title back in the page header, and add an Auto save on/off setting with coloured save states.

**Architecture:**
- **Rust** gains three settings fields, new menu items and events, and one command (`window_title_set`, acting on the calling window).
- **The React shell** drops `TopBar`. It gains:
  - `ActionButton`: a disclosure with Edit / Global view / Search;
  - `VaultMenu`: a popover on the sidebar's vault name, the cross-platform path to Settings, Open and Close;
  - the sidebar collapse.
- **`PageHeader`** renders the title and subtitle.
- **`PageDoc`** consults `autoSave`. A single `confirmUnsaved()` prompt guards leaving a page, closing the vault and closing a window when auto save is off.

**Tech stack:** Tauri 2 (Rust, muda menus), React 19, zustand, CSS modules, vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-m5b-feedback-design.md` §2, §6 and the amendments in §11.

## Global Constraints
- Safari 15 floor: no `color-mix()`, lookbehind regexes or `structuredClone`. Code must be `freezePrototype`-safe.
- i18n: en and es, kept at parity (`pnpm check:i18n`).
- axe-clean in light and dark. Every control is keyboard-reachable, and colour is never the only signal.
- Every new command runs async through `blocking()` and has a real-ACL test, allowed in main and denied where not listed.
- No new npm packages. No network.
- Settings: unknown keys survive, and a bad value resets only its own field (`parse_lenient`).

## Review Focus
1. **Auto save off and a page switch while text is unsaved.** Choosing Cancel keeps the page and its text on screen; Don't Save drops the text and never writes it; Save writes, then switches.
2. **Auto save off and quitting or closing the window with unsaved pages.** One prompt appears. Cancel keeps the window open; Don't Save closes without writing.
3. **Auto save toggled on while a page is unsaved.** The page saves within the autosave delay. When toggled off mid-typing, no further writes happen; a write already started may finish.
4. **External change merging while unsaved with auto save off.** The merge happens in memory only and nothing is written. This is a test in the `pageDoc` suite.
5. **The floating button never covers text.** The editor's scroll area has bottom padding, and the button stays clickable over Global View controls. Pinned in e2e by checking the last line's bounding box.

**Produces:**
- **Settings fields:** `autoSave: bool` (default true), `sidebarCollapsed: bool` (default false), `actionButton: "bottomRight" | "bottomLeft" | "topRight"` (default `bottomRight`).
- **Events:**
  - `menu:settings`, sent to the focused window;
  - `menu:vault`, payload `"open" | "close"`, sent to main;
  - `menu:save`, sent to the focused window;
  - `menu:sidebar`, sent to main.
- **Command:** `window_title_set(title: String)`, which sets the caller's title. Titles longer than 200 characters are cut, and control characters are removed.
