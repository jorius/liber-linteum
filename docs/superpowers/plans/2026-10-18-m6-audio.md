# M6 Audio clips Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** record microphone clips into the open page as `![[clip-….wav]]`, upload existing clips, and play audio embeds with an accessible player that plays one clip at a time.

**Architecture:**
- `liber-audio` (no Tauri) owns capture behind a `Host` trait: `CpalHost` in the app, `SyntheticHost` in every test. A blocking `record()` loop writes a WAV with hound and reports levels every 50 ms.
- The desktop crate runs `record()` on a dedicated thread per take, into the app cache. On stop it imports the WAV with the existing `import_attachment`.
- The page reserves the insertion point with the drop machinery that already exists (`addPending` / `land` in `attachments.ts`). The clip therefore lands where the cursor was, in the page the take started on.

**Tech stack:** cpal 0.18.2, hound 3.5.1, Tauri 2 commands and events, React 19 with zustand, CodeMirror 6.

**Spec:** `docs/superpowers/specs/2026-10-14-m6-audio-design.md`, §1–§9 as amended by §10 (batch 6).

## Global constraints

- Automated tests never open a real microphone.
  - Rust tests build the app through `configure(…, Some(dirs))`, which installs `SyntheticHost`.
  - TS and e2e tests mock IPC.
- WAV only (§10.1). There is no format toggle and no `recordingFormat` setting.
- Every command is async via `blocking()` (start, stop, pick, devices). Each has real-ACL tests and is absent from `capabilities/file.json`.
- Archived pages, text files and file windows can't record (§10.4).
- i18n en and es; axe-clean in light and dark; keyboard parity; Safari 15 floor (no lookbehind, no `structuredClone`, no `color-mix`).
- Signed commits with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review focus

1. **The take outlives its page.** The user switches pages, or closes the vault, mid-take. The clip must land in the page the take started on, or stay in the cache and be reported. It must never land in the page now shown. Test: switch the page, then stop.
2. **Stop pressed twice, or Stop then Cancel, while saving.** Exactly one clip, with no orphaned temp file. Test: two stops, then a single import.
3. **A device disappears mid-take.** The partial take is kept and Stop still works. Test: a synthetic host that ends early.
4. **Quit while recording.** `mayClose` stops and inserts before saving pages. Test: `mayClose` with an active take.
5. **Two players.** Starting B pauses A; leaving the page pauses everything. Test: a registry unit test plus unmount.

### Task 2: `CpalHost`

**Files:** `crates/liber-audio/src/cpal_host.rs`

**Interfaces:** `pub struct CpalHost;` implementing `Host`.

**Behaviour:**
- **Devices:** `default_host().input_devices()`; the id is `device.id()` and the name is `device.to_string()`, with the default device first.
- **Capture:**
  - opens the device (by id, else the default) with `default_input_config()`;
  - builds an input stream for i16, i32, f32 or u16, converting to f32 into an mpsc channel;
  - loops `recv_timeout(20 ms)` until `stop`, or until the error callback reports a lost device;
  - drops the stream on the capture thread, since a cpal `Stream` isn't `Send` everywhere.
- **Errors:** cpal `PermissionDenied` maps to `AudioError::Permission`; others map to `AudioError::Device(String)`.
- No test opens it. A compile-only check comes through `cargo check` and `cargo xwin check`.

**Commit:** `feat(audio): the cpal host — devices and capture on the recording thread (M6 §3)`

**Interfaces (produced):**
- `audio_devices() -> Vec<{ id, name, isDefault }>`
- `audio_record_start(page, device?, name) -> { recordingId }`:
  - `name` must match `clip-\d{8}-\d{6}`;
  - refuses archived or missing pages and a second take (`busy`, mapped to `alreadyExists`);
  - emits `audio:level { recordingId, rms, peak, elapsedMs, ended }` to the main window.
- `audio_record_stop(recordingId) -> AttachedDto`: joins the thread, `import_attachment`s the temp WAV, then deletes it.
- `audio_record_cancel(recordingId)`: stops and deletes the temp file.
- `audio_pick(page) -> Option<AttachedDto>`: a Rust dialog filtered to wav/mp3/m4a, then `import_attachment`. Tests use the `cover_picker` hook.
- `AudioState { host: Arc<dyn Host>, take: Mutex<Option<Take>> }`: `configure` installs `SyntheticHost` when `dirs` is `Some` (tests) and `CpalHost` otherwise.
