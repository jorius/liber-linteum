# M4b, part 3, Stream C — Files and links: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Format bar gets an **Attach** button: it opens the OS file dialog, then asks whether to copy the files into the vault or link them where they are. New attachments follow a per-vault **link format**, and an app setting shows each attachment's **location on disk**. Notes can link and embed files **outside the vault** by absolute or relative paths and `file:` URLs, served only through an allow-list.

**Architecture:**
- **Path recognition (`nimw-markdown`, pure, host-independent):** `external::external_target(kind, target, source)` sorts a link target as a Windows drive or UNC path, a POSIX path, a `file:` URL, or a relative path that climbs above the vault root. `has_scheme` no longer takes a drive letter for a URL scheme, and Markdown links with `file:` are kept.
- **The session (`nimw-session::external`):**
  - turns those into absolute paths with the vault root;
  - answers `externals(source, targets)` (path, exists, listed);
  - `external_file(path)` is the single checked gate (allow-list, host form, no hidden components lexically or after symlinks, regular file).
- **The allow-list:** every unresolved body link in the index whose computed path equals the request. It's found through `target_key`, whose base name now splits on `\` too (index schema 1 → 2).
- **The asset protocol:** serves externals under the reserved `/.external/<one encoded segment>`. Hidden paths are never served from the vault, so this can't collide with a vault file.
- **Tauri:** `links_external`, `external_open` and `external_reveal`, plus `file_pick` (a Rust-side dialog that grants the picked paths for `attachment_import`, like drops).
- **Link format:** `.nimw/vault.json` `attachmentLinkFormat`, falling back to Obsidian's `newLinkFormat`. `Attached` carries `url` for the absolute form.
- **UI:**
  - an Attach button with a Copy-or-Link popup;
  - a link format select in Settings → This vault;
  - `showAttachmentPaths` in Settings → Editor, with captions on embeds;
  - external embeds and links in the preview and Live Preview.

**Tech Stack:**
- Rust (`nimw-markdown`, `nimw-index`, `nimw-session`, `nimw-vault`, Tauri 2.12 with `tauri-plugin-dialog`/`-opener`);
- React 19 + TS, CodeMirror 6, zustand;
- Vitest (jsdom), Playwright (Chromium + WebKit).
- No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-15-m4b-part3-design.md` (§7, §8, §9). §15 records this stream's amendments.

## Global Constraints

- **Security (§9):**
  - the webview can only read or open an external file that some indexed note of the open vault links to;
  - only regular files;
  - no component starting with `.` (lexical or after symlinks);
  - responses keep `CSP: default-src 'none'; sandbox`, `nosniff`, `no-store`;
  - nothing opens on its own;
  - programs and scripts are refused by `check_openable` (M3 rule).
- **Imports:** outside paths are imported only when the OS gave them to Rust (a drop or a dialog Rust opened); a grant lasts two minutes and is used once.
- **Every new Tauri command** needs:
  - `build.rs` COMMANDS;
  - `generate_handler!`;
  - `capabilities/main.json` `allow-…`;
  - the `tests/commands.rs` COMMANDS list (real-ACL test).
- **Notes and Obsidian's files:** notes are never written by a setting; Obsidian's `.obsidian/app.json` is never written.
- **Safari 15 floor:** no `.at()`, `Object.hasOwn`, `structuredClone`, regex lookbehind or `color-mix` in app code (`jsCompat`/`cssCompat`).
- **i18n:** en + es (ICU), namespaces `editor.attach.*`, `settings.links.*`, `preview.external.*`.
- **Accessibility:** axe-clean in light and dark; keyboard parity; focus returns to the editor after the popup.
- **Zero network:** every new e2e test checks requests and CSP violations.

## Review Focus

1. **A note links `![[C:\Users\me\.ssh\id_rsa]]` or `![](file:///Users/me/.ssh/id_rsa)`:** nothing is served or opened (hidden component), whatever the encoding of the request.
2. **A symlink in an allowed place points into a hidden folder, or at a folder:** it's refused.
3. **The user types `![[D:\Pics\a.png]]` and the preview renders before the page is saved:** the image shows "Loading…", then the picture once the save indexes the link. It's never a broken image.
4. **Absolute paths written on another OS** (`D:\…` opened on macOS; `/Users/…` on Windows): "Not found: <path>", never a read relative to the working directory.
5. **"Absolute path on disk" chosen, then an image pasted:** `![](file:///…/Pasted%20image%20….png)` is inserted and shows at once.

### Task 1: Recognise paths outside the vault (`nimw-markdown`)

**Files:** create `crates/nimw-markdown/src/external.rs`; modify `body.rs`, `resolve.rs`, `lib.rs`.

**Interfaces (Produces):**
```rust
pub enum DiskPath { Windows(String), Posix(String) }   // normalized absolute
pub enum ExternalTarget { Absolute(DiskPath), AboveRoot { up: usize, rest: Vec<String> } }
pub fn external_target(kind: LinkKind, target: &str, source: &str) -> Option<ExternalTarget>;
```

**Tests:**
- `external.rs`:
  - drive with `\` and `/`;
  - UNC;
  - `file:///D:/…`, `file:///Users/…`, `file://server/share/…`, `file://localhost/…`;
  - percent-decoding only for wiki kinds;
  - a POSIX `/…`;
  - `./` and `../` (inside: `None`; above the root: `AboveRoot`);
  - `..` normalisation clamps at the drive or root;
  - NUL refused;
  - bare names and frontmatter kinds give `None`;
  - `D:relative` gives `None`.
- `body.rs`:
  - `![](D:\x.png)` and `![](file:///x.png)` are now links;
  - `https:` and `obsidian:` are still dropped.
- `resolve.rs`: `link_key("D:\\Docs\\x.pdf") == "x.pdf"`.

### Task 2: The allow-list, `externals` and `external_file` (`nimw-session`, `nimw-index`)

**Files:** create `crates/nimw-session/src/external.rs`; modify `schema.rs` (version 2) and `lib.rs`.

**Interfaces:**
```rust
pub struct ExternalFile { pub path: String, pub exists: bool, pub listed: bool }
impl VaultSession {
  pub fn externals(&self, source: &VaultPath, targets: &[(LinkKind, String)]) -> Result<Vec<Option<ExternalFile>>>;
  pub fn external_allowed(&self, path: &str) -> Result<bool>;
  pub fn external_file(&self, path: &str) -> Result<PathBuf>;   // NotPermitted / NotFound
}
pub fn file_url(path: &Path) -> String;
```

**Tests** (`crates/nimw-session/tests/external.rs`):
- listed once a page linking the file is written;
- unlisted path refused;
- hidden component refused (lexical, and a symlink into `.secret/`);
- a folder refused;
- `..` tricks normalised before the check;
- a vault target is not external;
- a missing file: `exists: false`;
- a Windows form on a Unix host: `exists: false`, never read;
- `file_url` forms (drive, UNC, POSIX, spaces, `#`, `%`, parentheses).
