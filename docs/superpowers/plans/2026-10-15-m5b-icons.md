# M5b Stream B — Sidebar row quick actions and optional emoji icons: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pages, folders and the vault can carry an optional emoji. It shows everywhere their name shows. Sidebar rows get hover/focus quick actions: +, ☺, 🗑 and ….

**Architecture:**
- **One source for icons.** Each explorer `TreeNode` carries its icon from Rust:
  - **pages:** frontmatter `icon:`, indexed in `pages.icon` (schema 4);
  - **folders:** `.nimw/vault.json` `folderIcons`;
  - **the vault:** `VaultInfo.icon` from `.nimw/vault.json` `icon`.
- **Lookups:** every other surface looks icons up by path in `useVaultStore.nodes`. That covers breadcrumbs, Global View cards, search hits, `[[` autocomplete and the page header. No DTO besides the tree, vault info and recent vaults changes.
- **Writes:**
  - a page icon goes through the frontmatter edit path: the live document when open, otherwise read + CAS write, as `related:` does;
  - folder and vault icons go through two new commands.
- **The picker:** a popover with lazy-loaded, bundled emoji data generated once from Unicode `emoji-test.txt` and the CLDR annotations (en, es).

**Tech Stack:**
- Rust: nimw-markdown, nimw-index (SQLite), nimw-vault, nimw-session, Tauri commands.
- Frontend: React 19, zustand, i18next, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-15-m5b-feedback-design.md` §3, §4 (amendments in §12).

## Global Constraints
- Icons are optional: no placeholder glyph in the tree when there is none.
- Rust validation: an icon is one extended grapheme cluster, ≤ 32 bytes, and an emoji (pictographic, keycap or flag). Anything else is refused on write and ignored on read.
- No network at runtime. Emoji data is a committed static file, lazy-loaded when the picker opens.
- i18n en + es (`pnpm check:i18n`); axe-clean light and dark; keyboard parity; Safari 15 floor (no lookbehind, `structuredClone`, `color-mix` or `.at(`); `freezePrototype`-safe.
- Every new command async via `blocking()`, with a real-ACL test. Main window only: denied in `file-*` windows.
- The tree keeps one tab stop. Row actions are pointer targets (`tabIndex=-1`); keyboard users reach them through keys and the … menu.
- Stream C reroutes trash: 🗑, Delete and ⌘⌫ all call `requestTrash(path)` from `features/explorer/trashAction.ts`.

## Review Focus
1. **Icon on a page that isn't open, with a CRLF/BOM file or invalid frontmatter.** The icon is written by CAS without touching other bytes; invalid YAML gives a toast and no write.
2. **Folder icon after the folder is renamed or moved, inside the app or in Finder, then deleted.** The icon follows the rename and is forgotten on delete.
3. **Hand-edited `icon: hello`, or a ZWJ family emoji, a flag, a keycap.** Text is ignored; real emoji show.
4. **Row actions with a long name in a narrow sidebar.** The actions don't cover the name's focus ring, and below 220 px only … shows.
5. **The picker on keyboard only, Spanish search ("corazón") and accent-free ("corazon").** It finds ❤️; Escape returns focus to the trigger.
