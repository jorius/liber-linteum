# M2c — Page extras Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Covers (add, change, reposition, remove) and subtitles edited in the page header; pasted images and files dropped from the OS saved into the vault with Obsidian-compatible embeds; `[[` / `![[` autocomplete with headings; a ⌘K "Link to…" picker; "Create page" that creates folders; raw HTML blocks rendered in Live Preview; and a per-vault attachment setting that follows Obsidian's.

**Architecture:** Rust owns every file that enters the vault: `liber-vault` resolves where attachments go (Obsidian's `attachmentFolderPath` first, re-read on each save) and streams create-only copies; `liber-session` names, dedupes, indexes and links them, and ranks `[[` suggestions with the shortest unique target. Outside paths reach Rust only from native drop events (one-use grants) or a dialog Rust opens itself; pastes travel as raw IPC bytes. The UI edits frontmatter byte-minimally (yaml Document ranges) as undoable CodeMirror transactions, and adds CodeMirror extensions for paste/drop and autocomplete.

**Tech Stack:** Tauri 2.12 (Rust 2024, `tauri-plugin-dialog` 2.8 Rust API), `yaml` 2.9 Document API, React 19, TypeScript 6, zustand 5, CodeMirror 6 (+ `@codemirror/autocomplete` 6.20.3, already in the lockfile), Vitest 5 + jsdom + Testing Library + axe-core, Playwright (Chromium + WebKit), pnpm 12, cargo.

**Spec:** `docs/superpowers/specs/2026-10-14-m2c-page-extras-design.md` (section numbers below refer to it; §12 lists the decisions taken for the maintainer, §13 this plan's amendments). Previous hand-off: `docs/handoff/2026-10-13-m2b-editor-ux-handoff.md`.

```rust
#[test]
fn m2c_import_file_streams_a_create_only_copy() {
    let (dir, vault) = fresh();
    let outside = tempfile::tempdir().unwrap();
    let src = outside.path().join("photo.png");
    let bytes: Vec<u8> = (0..200_000u32).map(|i| (i % 251) as u8).collect();
    std::fs::write(&src, &bytes).unwrap();
    let hash = vault.import_file(&src, &vp("photo.png")).unwrap();
    assert_eq!(hash, Hash::of(&bytes));
    assert_eq!(std::fs::read(dir.path().join("photo.png")).unwrap(), bytes);
    // Never overwrites, leaves no temp file behind.
    std::fs::write(&src, b"other").unwrap();
    assert!(matches!(
        vault.import_file(&src, &vp("photo.png")),
        Err(VaultError::AlreadyExists(_))
    ));
    assert_eq!(std::fs::read(dir.path().join("photo.png")).unwrap(), bytes);
    let names: Vec<_> = std::fs::read_dir(dir.path())
        .unwrap()
        .map(|e| e.unwrap().file_name().into_string().unwrap())
        .collect();
    assert_eq!(names, ["photo.png"]);
    // Missing parent folder.
    assert!(matches!(
        vault.import_file(&src, &vp("no/such/x.png")),
        Err(VaultError::NotFound(_))
    ));
}
```

```rust
//! dropped files, covers), Liber Linteum's attachment setting and `[[` suggestions.

use crate::error::{Result, SessionError};
use crate::session::{
    FORBIDDEN_NAME_CHARS, VaultSession, clamp_ns, folder_row, is_page_path, validate_name,
};

/// A file saved into (or found in) the vault for a page.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Attached {
    pub path: VaultPath,
    /// Wiki-style target that resolves from the page back to `path`.
    pub link: String,
    /// `false` when the dropped file already lived in the vault.
    pub copied: bool,
}

/// One `[[` / `![[` suggestion (M2c §7.2).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct LinkSuggestion {
    pub path: String,
    pub kind: FileKind,
    /// Pages only: the page's title (first H1, else the file name).

    pub target: String,

/// A name usable in the vault: characters `validate_name` refuses become `-`,
/// leading dots too (no hidden files); empty becomes `file` (M2c §5.3).
pub fn sanitize_file_name(name: &str) -> String {
    let mut out: String = name
        .trim()
        .chars()
        .map(|c| {
            if FORBIDDEN_NAME_CHARS.contains(&c) || c.is_control() {
                '-'
            } else {
                c
            }
        })
        .collect();
    if out.starts_with('.') {
        out.replace_range(..1, "-");
    }
    if out.trim().is_empty() {
        out = "file".to_string();
    }
    out
}

/// Frontmatter `cover:` value for `file` on `page` (M2c §2): relative to the
/// page's folder when the file is inside it, else vault-rooted (`/…`).
pub fn cover_reference(page: &VaultPath, file: &VaultPath) -> String {
    let here = page.parent().unwrap_or_else(VaultPath::root);
    if here.is_root() {
        return file.to_string();
    }
    if file.starts_with(&here) && file != &here {
        return file.as_str()[here.as_str().len() + 1..].to_string();
    }
    format!("/{file}")
}

fn split_ext(name: &str) -> (&str, Option<&str>) {
    match name.rfind('.') {
        Some(i) if i > 0 && i + 1 < name.len() => (&name[..i], Some(&name[i + 1..])),
        _ => (name, None),
    }
}

impl VaultSession {
    /// Saves pasted bytes as `name` in the page's attachment folder.
    pub fn save_attachment(&self, page: &VaultPath, name: &str, bytes: &[u8]) -> Result<Attached> {
        self.place(page, name, |dest| self.vault.write_cas(dest, bytes, None))
    }

    /// Copies the outside file `src` into the page's attachment folder; a file
    /// already inside the vault is only linked. Folders are refused.
    pub fn import_attachment(&self, page: &VaultPath, src: &Path) -> Result<Attached> {
        let shown = src.display().to_string();
        let meta = std::fs::metadata(src).map_err(|e| match e.kind() {
            std::io::ErrorKind::NotFound => {
                SessionError::Vault(VaultError::NotFound(shown.clone()))
            }
            _ => SessionError::Vault(VaultError::Io {
                path: shown.clone(),
                source: e,
            }),
        })?;
        if !meta.is_file() {
            return Err(SessionError::NotAFile(shown));
        }
        let real = dunce::canonicalize(src).map_err(|e| {
            SessionError::Vault(VaultError::Io {
                path: shown.clone(),
                source: e,
            })
        })?;
        if let Ok(inside) = VaultPath::from_fs_path(self.vault.root(), &real)
            && self.vault.stat(&inside)?.is_some()
        {
            let link = self.link_to(page, &inside)?;
            return Ok(Attached {
                path: inside,
                link,
                copied: false,
            });
        }
        let name = src
            .file_name()
            .map(|n| n.to_string_lossy().into_owned())
            .unwrap_or_default();
        self.place(page, &name, |dest| self.vault.import_file(&real, dest))
    }

    pub fn attachment_settings(&self) -> AttachmentConfig {

    /// Stores Liber Linteum's attachment setting. Refused while Obsidian's applies.
    pub fn set_attachment_settings(&self, mode: &str, path: &str) -> Result<()> {
        if self.vault.attachment_config().obsidian.is_some() {

    /// (M2c §6): exact, prefix, word start, substring, then subsequence; ties
    /// prefer pages (attachments for embeds), shorter paths, newer files. An
    /// empty query lists the most recently modified files.
    pub fn link_suggest(
        &self,
        source: &VaultPath,
        query: &str,
        embed: bool,
        limit: usize,
    ) -> Result<Vec<LinkSuggestion>> {
        let (candidates, files) = {
            let index = self.index();
            (index.link_candidates()?, index.file_set()?)
        };
        let q = name_key(query.trim());
        // Pages first for `[[`, attachments first for `![[`.
        let preferred = |c: &LinkCandidate| (c.kind == FileKind::Page) != embed;
        let mut scored: Vec<(u8, &LinkCandidate)> = candidates
            .iter()
            .filter_map(|c| score(&q, c).map(|s| (s, c)))
            .collect();
        scored.sort_by(|(sa, a), (sb, b)| {
            sb.cmp(sa)
                .then_with(|| preferred(b).cmp(&preferred(a)))
                .then_with(|| {
                    if q.is_empty() {
                        std::cmp::Ordering::Equal
                    } else {
                        a.path.len().cmp(&b.path.len())
                    }
                })
                .then_with(|| b.mtime_ns.cmp(&a.mtime_ns))
                .then_with(|| a.path.cmp(&b.path))
        });
        let kind = if embed {
            LinkKind::Embed
        } else {
            LinkKind::Wiki
        };
        Ok(scored
            .into_iter()
            .take(limit)
            .map(|(_, c)| LinkSuggestion {
                path: c.path.clone(),
                kind: c.kind,
                title: c.title.clone(),
                target: shortest_unique_target(&c.path, source.as_str(), &files, kind, false),
            })
            .collect())
    }

    /// Creates the attachment folder, writes under the first free name
    /// (`name`, `name 1`, …), indexes the result and links it from `page`.
    fn place(
        &self,
        page: &VaultPath,
        name: &str,
        write: impl Fn(&VaultPath) -> liber_vault::Result<Hash>,
    ) -> Result<Attached> {
        let dir = self.vault.attachment_policy().dir_for(page)?;
        for folder in self.vault.create_dir_all(&dir)? {
            if let Some(entry) = self.vault.stat(&folder)? {
                self.index()
                    .transaction(|tx| tx.upsert_file(&folder_row(&entry)))?;
            }
        }
        let name = sanitize_file_name(name);
        let (stem, ext) = split_ext(&name);
        for n in 0u32.. {
            let candidate = match (n, ext) {
                (0, _) => name.clone(),
                (n, Some(ext)) => format!("{stem} {n}.{ext}"),
                (n, None) => format!("{stem} {n}"),
            };
            let path = dir.join(&candidate)?;
            match write(&path) {
                Ok(hash) => {
                    self.index_new_file(&path, hash)?;
                    let link = self.link_to(page, &path)?;
                    return Ok(Attached {
                        path,
                        link,
                        copied: true,
                    });
                }
                Err(VaultError::AlreadyExists(_)) => continue,
                Err(e) => return Err(e.into()),
            }
        }
        unreachable!("the loop only ends by returning")
    }

    /// Indexes a file the session just created (pages are parsed) and
    /// re-resolves links that may now point at it. Files hidden by an exclude
    /// glob are left out of the index.
    fn index_new_file(&self, path: &VaultPath, hash: Hash) -> Result<()> {
        let Some(entry) = self.vault.stat(path)? else {
            return Ok(());
        };
        if is_page_path(path.as_str())
            && let Ok((text, _)) = self.vault.read_to_string(path)
        {
            self.reindex_written(path, &text, hash)?;
        } else {
            let row = FileRow {
                path: path.to_string(),
                kind: FileKind::Attachment,
                mtime_ns: clamp_ns(entry.mtime_ns),
                size: entry.size,
                hash: Some(hash.to_hex()),
            };
            self.index().transaction(|tx| tx.upsert_file(&row))?;
        }
        let mut index = self.index();
        let files = index.file_set()?;
        index.resolve_affected(&files, &[link_key(path.as_str())])?;
        Ok(())
    }

    fn link_to(&self, page: &VaultPath, path: &VaultPath) -> Result<String> {
        let files = self.index().file_set()?;
        Ok(shortest_unique_target(
            path.as_str(),
            page.as_str(),
            &files,
            LinkKind::Embed,
            false,
        ))
    }
}

/// Best match of `q` (already `name_key`ed) against a candidate's name, title
/// and path: 5 exact, 4 prefix, 3 word start, 2 substring, 1 subsequence.
fn score(q: &str, c: &LinkCandidate) -> Option<u8> {
    if q.is_empty() {
        return Some(0);
    }
    let base = c.path.rsplit('/').next().unwrap_or(&c.path);
    let strip_md = |s: &str| -> String {
        if c.kind == FileKind::Page && s.to_lowercase().ends_with(".md") {
            s[..s.len() - 3].to_string()
        } else {
            s.to_string()
        }
    };
    let name = name_key(&strip_md(base));
    let title = c.title.as_deref().map(name_key);
    let path = name_key(&strip_md(&c.path));
    let mut best = None;
    for (field, subsequence) in [(Some(name), true), (title, true), (Some(path), false)] {
        let Some(field) = field else { continue };
        let s = field_score(q, &field, subsequence);
        best = best.max(s);
    }
    best
}

fn field_score(q: &str, field: &str, subsequence: bool) -> Option<u8> {
    if field == q {
        return Some(5);
    }
    if field.starts_with(q) {
        return Some(4);
    }
    let word_start = field.match_indices(q).any(|(i, _)| {
        field[..i]
            .chars()
            .next_back()
            .is_some_and(|c| matches!(c, ' ' | '-' | '_' | '/' | '.' | '('))
    });
    if word_start {
        return Some(3);
    }
    if field.contains(q) {
        return Some(2);
    }
    if subsequence {
        let mut rest = field.chars();
        if q.chars().all(|qc| rest.any(|fc| fc == qc)) {
            return Some(1);
        }
    }
    None
}
```

```rust
//! M2c page extras (spec §7): pasted and dropped attachments, cover upload,
//! `[[` suggestions and the vault's attachment setting. Thin wrappers over
//! `liber-session`; outside paths only come from native drops (`drops`) or a
//! dialog Rust opens itself (spec §8).

use crate::dto::{
    AttachedDto, AttachmentsDto, CoverDto, ImportResultDto, LinkSuggestionDto, VaultSettingsDto,
    VaultSettingsPatch,
};
use crate::error::{CmdResult, CommandError, ErrorKind};
use crate::state::AppState;
use crate::vault_commands::blocking;
use liber_session::cover_reference;
use liber_vault::VaultPath;
use percent_encoding::percent_decode_str;
use std::path::PathBuf;
use tauri::ipc::{InvokeBody, Request};
use tauri::{AppHandle, Manager, Runtime};
use tauri_plugin_dialog::DialogExt;

/// Largest pasted image (spec §7.3).
pub const MAX_PASTE_BYTES: usize = 64 * 1024 * 1024;
/// Image types a paste may save.
pub const PASTE_EXTENSIONS: &[&str] = &["png", "jpg", "gif", "webp"];
/// Image types the cover dialog offers.
pub const COVER_EXTENSIONS: &[&str] = &["png", "jpg", "jpeg", "gif", "webp", "avif", "svg", "bmp"];
/// Most suggestions per `[[` query.
pub const SUGGEST_LIMIT: usize = 50;

fn invalid(message: impl Into<String>) -> CommandError {
    CommandError::new(ErrorKind::InvalidName, message)
}

/// The page path, file name and bytes of a paste: a raw body with
/// percent-encoded `x-liber-page` / `x-liber-name` headers.
fn paste_parts(request: &Request<'_>) -> CmdResult<(String, String, Vec<u8>)> {
    let InvokeBody::Raw(bytes) = request.body() else {
        return Err(invalid("expected the image bytes as a raw body"));
    };
    if bytes.len() > MAX_PASTE_BYTES {
        return Err(CommandError::new(
            ErrorKind::TooLarge,
            format!("pasted images are limited to {} MiB", MAX_PASTE_BYTES >> 20),
        ));
    }
    let header = |name: &str| -> CmdResult<String> {
        let raw = request
            .headers()
            .get(name)
            .and_then(|v| v.to_str().ok())
            .ok_or_else(|| invalid(format!("missing {name}")))?;
        percent_decode_str(raw)
            .decode_utf8()
            .map(|s| s.into_owned())
            .map_err(|_| invalid(format!("{name} is not UTF-8")))
    };
    Ok((
        header("x-liber-page")?,
        header("x-liber-name")?,
        bytes.clone(),
    ))
}

pub(crate) fn attachment_paste_impl(
    state: &AppState,
    page: String,
    name: String,
    bytes: Vec<u8>,
) -> CmdResult<AttachedDto> {
    let session = state.session()?;
    let page = VaultPath::new(&page)?;
    let ext = name
        .rsplit_once('.')
        .map(|(_, e)| e.to_ascii_lowercase())
        .unwrap_or_default();
    if !PASTE_EXTENSIONS.contains(&ext.as_str()) {
        return Err(invalid("only png, jpg, gif and webp images can be pasted"));
    }
    if bytes.is_empty() {
        return Err(invalid("the pasted image is empty"));
    }
    Ok(session.save_attachment(&page, &name, &bytes)?.into())
}

    state: &AppState,
    page: String,

        .into_iter()

            let path = PathBuf::from(&source);
```

```rust
//! Native file drops (M2c §8). The OS tells Rust which paths were dropped; the
//! page may import those paths, each once, for two minutes. Any other path the
//! page names is refused, so a compromised page cannot copy arbitrary files
//! (e.g. `~/.ssh/…`) into the vault and read them back.

use crate::state::AppState;
use std::collections::VecDeque;
use std::path::{Path, PathBuf};
use std::time::{Duration, Instant};
use tauri::{DragDropEvent, Manager, Runtime, Webview, WebviewEvent, Window, WindowEvent};

/// How long a dropped path stays importable.
pub const GRANT_TTL: Duration = Duration::from_secs(120);
/// Most grants kept; the oldest go first.
pub const MAX_GRANTS: usize = 1000;

#[derive(Debug, Default)]
pub struct DropGrants {
    entries: VecDeque<(PathBuf, Instant)>,
}

impl DropGrants {
    pub fn grant(&mut self, paths: &[PathBuf], now: Instant) {
        self.prune(now);
        for path in paths {
            self.entries.push_back((path.clone(), now));
        }
        while self.entries.len() > MAX_GRANTS {
            self.entries.pop_front();
        }
    }

    /// Uses up the grant for `path`.
    pub fn take(&mut self, path: &Path, now: Instant) -> bool {
        self.prune(now);
        match self.entries.iter().position(|(p, _)| p == path) {
            Some(i) => {
                self.entries.remove(i);
                true
            }
            None => false,
        }
    }

    fn prune(&mut self, now: Instant) {
        self.entries
            .retain(|(_, at)| now.saturating_duration_since(*at) < GRANT_TTL);
    }
}

/// Registered with `.on_window_event` (webview windows report drops here).
pub fn on_window_event<R: Runtime>(window: &Window<R>, event: &WindowEvent) {
    if let WindowEvent::DragDrop(DragDropEvent::Drop { paths, .. }) = event
        && let Some(state) = window.try_state::<AppState>()
    {
        state.grant_drops(paths);
    }
}

/// Registered with `.on_webview_event` (child webviews report drops here).
pub fn on_webview_event<R: Runtime>(webview: &Webview<R>, event: &WebviewEvent) {
    if let WebviewEvent::DragDrop(DragDropEvent::Drop { paths, .. }) = event
        && let Some(state) = webview.try_state::<AppState>()
    {
        state.grant_drops(paths);
    }
}
```

```ts
// Frontmatter edits from the page header (M2c §4): cover, cover-y, subtitle.
// Only the touched keys' source text changes; every other line (order,
// comments, quoting, flow style) stays byte for byte. Invalid YAML is refused,
// never rewritten.
import { isMap, isScalar, parseDocument, stringify, type Pair } from 'yaml';
import { parsePage } from './parse';

export interface TextChange {
  from: number;
  to: number;
  insert: string;
}

/** `null` deletes the key. */
export type FrontmatterPatch = Record<string, string | number | null>;

export type FrontmatterEdit = { ok: true; change: TextChange | null } | { ok: false };

/** A leading `---` … `---` block, confirmed by the same parser the app uses. */
const BLOCK = /^---\n(?:[\s\S]*?\n)?---(?:\n|$)/;

/** One line of YAML for a scalar (newlines folded to spaces). */
function scalar(value: string | number): string {
  const v = typeof value === 'string' ? value.replace(/\s*\n\s*/g, ' ') : value;
  return stringify(v, { lineWidth: 0 }).replace(/\n$/, '');
}

/** End of the line `end` falls in (after its `\n`). */
function lineEnd(src: string, end: number): number {
  if (end > 0 && src[end - 1] === '\n') return end;
  const nl = src.indexOf('\n', end);
  return nl === -1 ? src.length : nl + 1;
}

/** Applies `patch` to the note's frontmatter; `change` is `null` when nothing
 *  changes. A note without frontmatter gets a new block at the top; a block
 *  left without any content is removed. */
export function setFrontmatter(text: string, patch: FrontmatterPatch): FrontmatterEdit {
  const m = BLOCK.exec(text);
  const block = m && parsePage(m[0]).frontmatter ? m[0] : null;
  if (!block) {
    const lines = Object.entries(patch)
      .filter((e): e is [string, string | number] => e[1] !== null)
      .map(([k, v]) => `${scalar(k)}: ${scalar(v)}\n`);
    if (!lines.length) return { ok: true, change: null };
    return { ok: true, change: { from: 0, to: 0, insert: `---\n${lines.join('')}---\n` } };
  }
  const innerFrom = 4;
  const innerTo = block.length - (block.endsWith('\n') ? 4 : 3);
  const src = text.slice(innerFrom, innerTo);
  const doc = parseDocument(src);
  if (doc.errors.length || (doc.contents !== null && !isMap(doc.contents))) return { ok: false };
  const pairs = (isMap(doc.contents) ? doc.contents.items : []) as Pair[];
  const keyOf = (p: Pair) => (isScalar(p.key) ? String(p.key.value) : null);

  // Edits on `src`, applied back to front.
  const edits: TextChange[] = [];
  let appended = '';
  for (const [key, value] of Object.entries(patch)) {
    const pair = pairs.find((p) => keyOf(p) === key);
    if (!pair) {
      if (value !== null) appended += `${scalar(key)}: ${scalar(value)}\n`;
      continue;
    }
    const k = pair.key as { range: [number, number, number] };
    const v = pair.value as { range?: [number, number, number]; toJSON?: () => unknown } | null;
    const end = lineEnd(src, v?.range?.[2] ?? k.range[2]);
    if (value === null) {
      edits.push({ from: k.range[0], to: end, insert: '' });
    } else if (isScalar(pair.value) && v?.range) {
      if (pair.value.value === value) continue;
      edits.push({ from: v.range[0], to: v.range[1], insert: scalar(value) });
    } else {
      const keySrc = src.slice(k.range[0], k.range[1]);
      edits.push({ from: k.range[0], to: end, insert: `${keySrc}: ${scalar(value)}\n` });
    }
  }
  if (!edits.length && !appended) return { ok: true, change: null };
  let next = src;
  for (const e of edits.sort((a, b) => b.from - a.from)) {
    next = next.slice(0, e.from) + e.insert + next.slice(e.to);
  }
  if (appended && next && !next.endsWith('\n')) next += '\n';
  next += appended;
  if (!next.trim()) {
    return { ok: true, change: { from: 0, to: block.length, insert: '' } };
  }
  return { ok: true, change: { from: innerFrom, to: innerTo, insert: next } };
}
```

```tsx
function useCover(page: Page): CoverState {
  const [state, setState] = useState<CoverState>({ kind: 'none' });
  useEffect(() => {
    const cover = page.cover?.trim();
    if (!cover) {
      setState({ kind: 'none' });
      return;
    }
    if (/^[a-z][a-z0-9+.-]*:/i.test(cover)) {

      if (!live) return;
      const path = res.ok ? res.value[0] : null;
      setState(path ? { kind: 'image', path } : { kind: 'missing' });
    });
    return () => {
      live = false;
    };
  }, [page.path, page.cover]);
  return state;
}
```

```tsx
 *  a click elsewhere saves, Escape restores, empty removes the key; switching
 *  apps mid-edit saves nothing (as for the title). */
export function PageSubtitle({ page, editable }: { page: Page; editable: boolean }) {
  const { t } = useTranslation();
  const current = page.subtitle ?? '';
  const [draft, setDraft] = useState(current);

      return;
    }
    void useEditorStore.getState().editFrontmatter({ subtitle: value || null });

      e.preventDefault();

      className={styles.subtitleInput}
      aria-label={t('page.subtitleLabel')}
      placeholder={t('page.subtitlePlaceholder')}
      value={draft}
      onChange={(e) => setDraft(e.target.value)}
      onKeyDown={onKeyDown}
      onBlur={() => {
        if (document.hasFocus()) commit();
```

```ts
// Pasted images and files dropped from the OS (M2c §5): saved into the vault
// by Rust, then an embed or link is inserted where they landed. Drops come
// from Tauri's native drag events (Rust only imports paths it saw dropped).
import { StateEffect, StateField, type Extension } from '@codemirror/state';
import { Decoration, EditorView, WidgetType, type DecorationSet } from '@codemirror/view';
import i18next from 'i18next';
import {
  attachmentImport,
  attachmentPaste,
  isTauri,
  onDragDrop,
  type CommandError,
  type DragDropPayload,
} from '../../ipc';
import { useEditorStore } from '../../stores/editorStore';
import { errorMessage } from '../../stores/messages';
import { useToastStore } from '../../stores/toastStore';
import { nameOf } from '../../stores/tree';
import { useVaultStore } from '../../stores/vaultStore';
import { pagePath } from './livePreview';

const PASTE_TYPES: Record<string, string> = {
  'image/png': 'png',
  'image/jpeg': 'jpg',
  'image/gif': 'gif',
  'image/webp': 'webp',
};

/** Files shown inline (`![[…]]`); anything else is linked (`[[…]]`). */
const EMBEDDED = new Set([
  ...['png', 'jpg', 'jpeg', 'gif', 'webp', 'avif', 'svg', 'bmp', 'pdf'],
  ...['mp3', 'm4a', 'wav', 'ogg', 'flac', 'mp4', 'mov', 'webm'],
]);

const pad = (n: number) => String(n).padStart(2, '0');

/** Obsidian's name for a pasted image (local time); `null` for other types. */
export function pastedName(at: Date, type: string): string | null {
  const ext = PASTE_TYPES[type];
  if (!ext) return null;
  const stamp =
    `${at.getFullYear()}${pad(at.getMonth() + 1)}${pad(at.getDate())}` +
    `${pad(at.getHours())}${pad(at.getMinutes())}${pad(at.getSeconds())}`;
  return `Pasted image ${stamp}.${ext}`;
}

/** The text inserted for a saved file whose wiki target is `link`. */
export function embedFor(link: string): string {
  const name = link.slice(link.lastIndexOf('/') + 1);
  const dot = name.lastIndexOf('.');
  const ext = dot > 0 ? name.slice(dot + 1).toLowerCase() : '';
  return EMBEDDED.has(ext) ? `![[${link}]]` : `[[${link}]]`;
}

// ---- drop caret / pending insertion point ----

/** Where dropped files will land; mapped through edits made while copying. */
const setDropAt = StateEffect.define<number | null>();

class CaretWidget extends WidgetType {
  toDOM(): HTMLElement {
    const el = document.createElement('span');
    el.className = 'cm-liber-drop-caret';
    el.setAttribute('aria-hidden', 'true');
    return el;
  }
}

const dropAt = StateField.define<number | null>({
  create: () => null,
  update(pos, tr) {
    for (const e of tr.effects) if (e.is(setDropAt)) return e.value;
    return pos === null ? null : tr.changes.mapPos(pos, 1);
  },
  provide: (f) =>
    EditorView.decorations.from(f, (pos): DecorationSet =>
      pos === null
        ? Decoration.none
        : Decoration.set([Decoration.widget({ widget: new CaretWidget(), side: 1 }).range(pos)]),
    ),
});

const caretTheme = EditorView.baseTheme({
  '.cm-liber-drop-caret': {
    display: 'inline-block',
    width: '2px',
    height: '1.2em',
    marginRight: '-2px',
    verticalAlign: 'text-bottom',
    background: 'var(--color-accent)',
  },
});

// ---- paste ----

function track(delta: number) {
  useEditorStore.setState((s) => ({ copying: Math.max(0, s.copying + delta) }));
}

async function pasteImages(view: EditorView, files: File[]) {
  const page = view.state.facet(pagePath)();
  const inserted: string[] = [];
  track(1);
  try {
    for (const file of files) {
      const name = pastedName(new Date(), file.type)!;
      const res = await attachmentPaste(page, name, new Uint8Array(await file.arrayBuffer()));
      if (res.ok) inserted.push(embedFor(res.value.link));
      else useToastStore.getState().push({ message: errorMessage(res.error), tone: 'error' });
    }
  } finally {
    track(-1);
  }
  if (!inserted.length) return;
  const text = inserted.join('\n');
  const { from, to } = view.state.selection.main;
  view.dispatch({
    changes: { from, to, insert: text },
    selection: { anchor: from + text.length },
    userEvent: 'input.paste',
  });
  void useVaultStore.getState().refreshTree();
}

const pasteHandler = EditorView.domEventHandlers({
  paste(e, view) {
    const data = e.clipboardData;
    if (!data || data.types.includes('text/plain')) return false;
    const files = [...data.files].filter((f) => PASTE_TYPES[f.type]);
    if (!files.length) return false;
    e.preventDefault();
    void pasteImages(view, files);
    return true;
  },
});

/** Paste handling and the drop caret, for every editor mode. */
export function attachmentHandlers(): Extension {
  return [pasteHandler, dropAt, caretTheme];
}

// ---- drop ----

/** The editor under a drag position (physical px from the webview's corner). */
function target(e: DragDropPayload): { view: EditorView; pos: number } | null {
  if (e.x === undefined || e.y === undefined) return null;
  const x = e.x / window.devicePixelRatio;
  const y = e.y / window.devicePixelRatio;
  const el = document.elementFromPoint?.(x, y)?.closest('.cm-editor');
  const view = el instanceof HTMLElement ? EditorView.findFromDOM(el) : null;
  if (!view) return null;
  const pos = view.posAtCoords({ x, y }) ?? view.state.selection.main.head;
  return { view, pos };
}

const failureLine = (source: string, error: CommandError) =>
  `${nameOf(source.replace(/[\\/]+$/, ''))}: ${errorMessage(error)}`;

async function dropFiles(view: EditorView, paths: string[]) {
  const page = view.state.facet(pagePath)();
  track(1);
  const res = await attachmentImport(page, paths).finally(() => track(-1));
  const pos = view.state.field(dropAt, false) ?? view.state.selection.main.head;
  view.dispatch({ effects: setDropAt.of(null) });
  if (!res.ok) {
    useToastStore.getState().push({ message: errorMessage(res.error), tone: 'error' });
    return;
  }
  const links = res.value.flatMap((r) => (r.ok ? [embedFor(r.ok.link)] : []));
  const failed = res.value.flatMap((r) => (r.err ? [failureLine(r.source, r.err)] : []));
  if (links.length) {
    const text = links.join('\n');
    view.dispatch({
      changes: { from: pos, insert: text },
      selection: { anchor: pos + text.length },
      userEvent: 'input.drop',
    });
    void useVaultStore.getState().refreshTree();
  }
  if (failed.length) {
    useToastStore.getState().push({
      message: i18next.t('attach.someFailed'),
      detail: failed,
      tone: 'error',
    });
  }
}

let caretView: EditorView | null = null;

function moveCaret(next: { view: EditorView; pos: number } | null) {
  if (caretView && caretView !== next?.view) {
    caretView.dispatch({ effects: setDropAt.of(null) });
  }
  caretView = next?.view ?? null;
  next?.view.dispatch({ effects: setDropAt.of(next.pos) });
}

function onDrag(e: DragDropPayload) {
  if (e.type === 'leave') return moveCaret(null);
  const hit = target(e);
  if (e.type !== 'drop') return moveCaret(hit);
  caretView = null;
  if (!hit) {
    useToastStore.getState().push({ message: i18next.t('attach.dropOnText') });
    return;
  }
  hit.view.dispatch({ effects: setDropAt.of(hit.pos) });
  void dropFiles(hit.view, e.paths ?? []);
}

/** Listens to native file drags for the whole window; returns the unsubscribe. */
export function installFileDrop(): Promise<() => void> {
  return onDragDrop(onDrag);
```

```ts
// `[[` / `![[` autocomplete (M2c §6): files from Rust's `link_suggest`
// (ranked there, with the shortest unique target), `#` headings parsed here.
// Picking a page whose title differs from its file name writes
// `[[file|Title]]`, so the link reads well and still resolves in Obsidian (PG-05).
import {
  acceptCompletion,
  autocompletion,
  pickedCompletion,
  type Completion,
  type CompletionContext,
  type CompletionResult,
} from '@codemirror/autocomplete';
import { Prec, type EditorState, type Extension } from '@codemirror/state';
import { EditorView, keymap } from '@codemirror/view';
import type { Heading, RootContent } from 'mdast';
import { linkSuggest, linksResolve, pageRead, type LinkSuggestion } from '../../ipc';
import { headingLinkText } from '../../markdown/headings';
import { parsePage } from '../../markdown/parse';
import { text as nodeText } from '../../markdown/section';
import { pagePath } from './livePreview';

export type LinkQuery =
  | { kind: 'file'; embed: boolean; query: string; from: number; closed: boolean }
  | {
      kind: 'heading';
      embed: boolean;
      page: string;
      query: string;
      from: number;
      closed: boolean;
    };

/** `[[` or `![[` and the text typed after it on this line (no `[`, `]`). */
const LINK_BEFORE = /(!?)\[\[([^[\]\n]*)$/;

/** The link being typed at `pos`, or `null` (aliases end the completion). */
export function linkQueryAt(state: EditorState, pos: number): LinkQuery | null {
  const line = state.doc.lineAt(pos);
  const m = LINK_BEFORE.exec(line.text.slice(0, pos - line.from));
  if (!m || m[2].includes('|')) return null;
  const inner = m[2];
  const embed = m[1] === '!';
  const closed = state.doc.sliceString(pos, pos + 2) === ']]';
  const hash = inner.indexOf('#');
  if (hash < 0) return { kind: 'file', embed, query: inner, from: pos - inner.length, closed };
  const query = inner.slice(hash + 1);
  return {
    kind: 'heading',
    embed,
    page: inner.slice(0, hash),
    query,
    from: pos - query.length,
    closed,
  };
}

const key = (s: string) => s.normalize('NFC').toLowerCase();
const baseName = (path: string) => path.slice(path.lastIndexOf('/') + 1);

/** PG-05: the title as an alias when it differs from the file name. */
function aliasFor(s: LinkSuggestion): string | null {
  if (s.kind !== 'page' || !s.title) return null;
  const stem = baseName(s.path).replace(/\.md$/i, '');
  if (key(s.title) === key(stem)) return null;
  const alias = s.title.replace(/[[\]\n]/g, ' ').trim();
  return alias || null;
}

/** Inserts `text` over the query, then `]]` (or steps over an existing one). */
function applyText(text: string, closed: boolean) {
  return (view: EditorView, completion: Completion, from: number, to: number) => {
    const insert = closed ? text : `${text}]]`;
    view.dispatch({
      changes: { from, to, insert },
      selection: { anchor: from + insert.length + (closed ? 2 : 0) },
      annotations: pickedCompletion.of(completion),
      userEvent: 'input.complete',
    });
  };
}

function fileOption(s: LinkSuggestion, q: LinkQuery): Completion {
  const alias = q.embed ? null : aliasFor(s);
  return {
    label: s.title ?? baseName(s.path),
    detail: s.path,
    type: s.kind === 'page' ? 'text' : 'variable',
    apply: applyText(alias ? `${s.target}|${alias}` : s.target, q.closed),
  };
}

interface HeadingItem {
  text: string;
  depth: number;
}

function headingsIn(source: string): HeadingItem[] {
  const out: HeadingItem[] = [];
  const walk = (nodes: RootContent[]) => {
    for (const n of nodes) {
      if (n.type === 'heading') {
        const text = nodeText(n).trim();
        if (text) out.push({ text, depth: (n as Heading).depth });
      } else if ('children' in n) walk(n.children as RootContent[]);
    }
  };
  walk(parsePage(source).tree.children);
  return out;
}

function pageText(path: string): Promise<string | null> {
  const hit = pageCache.get(path);
  if (hit && Date.now() - hit.at < PAGE_CACHE_MS) return hit.text;
  const text = pageRead(path).then((res) => (res.ok ? res.value.text : null));
  pageCache.set(path, { at: Date.now(), text });
  return text;
}

async function headingsFor(
  q: Extract<LinkQuery, { kind: 'heading' }>,
  state: EditorState,
  source: string,
): Promise<HeadingItem[]> {
```

```tsx
function obsidianPlace(value: string, t: TFunction): string {
  const v = value.trim();
  if (v === '/' || v === '') return t('vault.obsidianRoot');
  if (v === './' || v === '.') return t('vault.obsidianSame');

/** "This vault" (M2c §5.4): where new attachments go, stored in

  const { t } = useTranslation();

  const errorId = useId();

  const [path, setPath] = useState('attachments');

  const [error, setError] = useState<string | null>(null);

    let live = true;
    void vaultSettingsGet().then((res) => {
      if (!live || !res.ok || !res.value?.attachments) return;

      setPath(res.value.attachments.path);
      setObsidian(res.value.obsidian);
      setLoaded(true);
    });
    return () => {
      live = false;
    };

    const res = await vaultSettingsSet({ attachments: { mode: nextMode, path: nextPath } });
    if (!res.ok) setError(errorMessage(res.error));
    else setError(null);
  };
  const problem = (value: string): string | null => {
    const parts = mode === 'folder' ? value.split('/') : [value];
    for (const part of parts) {
      const bad = validateName(part);
      if (bad) {

          `explorer.nameErrors.${bad.key}`,
          bad.key === 'forbidden' ? { char: bad.char } : {},
        );
      }
    }
    return null;
  };

    setMode(next);
    setError(null);
    if (next === 'vault' || next === 'same') void save(next, '');
    else if (next === 'subfolder') {
      setPath('attachments');

    }
    void save(mode, value);
```

```ts
/** Requests that would leave the machine (the test server is 127.0.0.1). */
async function watchNetwork(page: Page) {
  const outside: string[] = [];
  page.on('request', (r) => {
    const url = new URL(r.url());
    const local =
      (url.protocol === 'http:' && url.hostname === '127.0.0.1') ||
      url.protocol === 'data:' ||
      // Vault files: liber-asset://localhost (macOS, Linux), http://liber-asset.localhost (Windows UA).
      url.protocol === 'liber-asset:' ||
      url.hostname === 'liber-asset.localhost';

  });
  await page.route(/^https?:\/\/(?!127\.0\.0\.1|liber-asset\.localhost)/, (route) => route.abort());
  return outside;
}
```
