# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Notes In My Way monorepo: five Rust core crates, a locked-down Tauri 2 shell, and a React/TypeScript UI with theme tokens, en/es i18n and the welcome screen. Prove one typed IPC round trip (`app_info`) works end to end, with lint, test and CI wired up.

**Architecture:** A Cargo workspace (`crates/*` plus `apps/desktop/src-tauri`) and a pnpm workspace (`apps/desktop`). The Rust crates never depend on Tauri. The UI reaches the backend only through `src/ipc/`. The zero-network rule is enforced from day one by CSP, by a Tauri capability allowlist, by ESLint bans and by cargo-deny bans.

**Tech Stack:** Tauri 2.12, Rust 1.99 (edition 2024), React 19.3, TypeScript 6.0, Vite 8, Vitest 5, i18next 26 + ICU, ESLint 10, Prettier 3, cargo-deny, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-12-architecture-design.md` (§10 "M0 scaffold contents"). The product spec is `notes-in-my-way-spec.md`, which Task 1 moves to `docs/product-spec.md`.

## Global Constraints

- License **GPL-3.0-or-later** for every crate and package (`license` field set everywhere).
- **Zero network (P1, NFR-04):**
  - No HTTP-client crates (`reqwest`, `ureq`, `isahc`, `curl`, `hyper`).
  - No `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource` or `navigator.sendBeacon` in UI code.
  - No remotely loaded fonts or assets.
- **Production CSP, exactly:** `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' asset: http://asset.localhost data: blob:; media-src 'self' asset: http://asset.localhost blob:; font-src 'self'; connect-src ipc: http://ipc.localhost; frame-src 'none'; object-src 'none'; base-uri 'none'; form-action 'none'`
- `crates/*` must not depend on `tauri`.
- UI code imports `@tauri-apps/api/core` only inside `apps/desktop/src/ipc/`.
- Every user-visible UI string comes from i18n. `en` and `es` keep identical key sets.
- Styling uses CSS Modules plus custom properties from `src/theme/tokens.css`. No hard-coded colors in components.

```rust
use pulldown_cmark::{Event, HeadingLevel, Options, Parser, Tag, TagEnd};

/// Page title (PG-01): visible text of the first H1, else the file stem.
pub fn extract_title(source: &str, file_stem: &str) -> String {
    let options = Options::ENABLE_YAML_STYLE_METADATA_BLOCKS
        | Options::ENABLE_TABLES
        | Options::ENABLE_TASKLISTS
        | Options::ENABLE_STRIKETHROUGH;
    let mut in_h1 = false;
    let mut text = String::new();
    for event in Parser::new_ext(source, options) {
        match event {
            Event::Start(Tag::Heading { level: HeadingLevel::H1, .. }) => {
                in_h1 = true;
                text.clear();
            }
            Event::End(TagEnd::Heading(HeadingLevel::H1)) => {
                in_h1 = false;
                let title = text.split_whitespace().collect::<Vec<_>>().join(" ");
                if !title.is_empty() {
                    return title;
                }
            }
            Event::Text(t) | Event::Code(t) if in_h1 => text.push_str(&t),
            Event::SoftBreak | Event::HardBreak if in_h1 => text.push(' '),
            _ => {}
        }
    }
    file_stem.to_string()
}
```

```rust
const NOTION_ID_LEN: usize = 32;

pub fn strip_notion_id(name: &str) -> String {
    let bytes = name.as_bytes();
    let mut found = None;
    for (i, &b) in bytes.iter().enumerate() {
        if b != b' ' {
            continue;
        }
        let id_end = i + 1 + NOTION_ID_LEN;
        if id_end > bytes.len() {
            break;
        }
        let is_id = bytes[i + 1..id_end]
            .iter()
            .all(|c| c.is_ascii_digit() || (b'a'..=b'f').contains(c));
        let at_boundary = matches!(bytes.get(id_end), None | Some(b'.') | Some(b'_'));
        if is_id && at_boundary {
            found = Some(i);
        }
    }
    match found {
        // ' ' and hex digits are ASCII, so these byte indices are char boundaries.
        Some(i) => format!("{}{}", &name[..i], &name[i + 1 + NOTION_ID_LEN..]),
        None => name.to_string(),
    }
}
```

```ts
import i18next from 'i18next';
import ICU from 'i18next-icu';
import { initReactI18next } from 'react-i18next';
import en from './locales/en.json';
import es from './locales/es.json';

// NFR-07: adding a language = add locales/<code>.json and one entry here.
const LOCALES = { en, es } as const;

export type Language = keyof typeof LOCALES;
export const SUPPORTED_LANGUAGES = Object.keys(LOCALES) as Language[];

// Q-I18N-1: first supported base language in the OS preference list, else English.
export function detectLanguage(preferred: readonly string[]): Language {
  for (const tag of preferred) {
    const base = tag.trim().toLowerCase().split(/[-_]/)[0];
    const match = SUPPORTED_LANGUAGES.find((lng) => lng === base);
    if (match) return match;
  }
  return 'en';
}

export async function initI18n(language: Language) {
  const resources = Object.fromEntries(
    Object.entries(LOCALES).map(([lng, translation]) => [lng, { translation }]),
  );
  await i18next
    .use(ICU)
    .use(initReactI18next)
    .init({ resources, lng: language, fallbackLng: 'en', interpolation: { escapeValue: false } });
  return i18next;
}
```

`apps/desktop/src/i18n/parity.ts` (types only, no enums, so Node can run it with type stripping):
```ts
function flattenKeys(value: unknown, prefix = ''): string[] {
  if (value === null || typeof value !== 'object' || Array.isArray(value)) return [prefix];
  return Object.entries(value).flatMap(([key, child]) =>
    flattenKeys(child, prefix ? `${prefix}.${key}` : key),
  );
}

export function findMissingKeys(locales: Record<string, unknown>): string[] {
  const keysByLocale = Object.entries(locales).map(
    ([locale, data]) => [locale, new Set(flattenKeys(data))] as const,
  );
  const allKeys = new Set(keysByLocale.flatMap(([, keys]) => [...keys]));
  const missing: string[] = [];
  for (const [locale, keys] of keysByLocale) {
    for (const key of allKeys) if (!keys.has(key)) missing.push(`${locale}: ${key}`);
  }
  return missing.sort();
}
```

```ts
import { useEffect, useState } from 'react';
import { appInfo } from '../ipc';

export function useAppVersion(): string | null {
  const [version, setVersion] = useState<string | null>(null);
  useEffect(() => {
    let cancelled = false;
    appInfo()
      .then((info) => {
        if (!cancelled) setVersion(info.version);
      })
      .catch(() => {
        // Not running inside Tauri (e.g. plain `vite` in a browser): the version stays hidden.
      });
    return () => {
      cancelled = true;
    };
  }, []);
  return version;
}
```
