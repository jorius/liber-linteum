## 4. Rulings to confirm

1. **Code fences keep their two lines.** In Live Preview the opening line becomes the header row and the closing line stays as an empty line, so nothing moves when the source shows. It costs about one extra line of height per block.
2. **List markers reveal per line,** on the cursor's own line only.
3. **Copy copies the parsed code.** A block indented under a list item is copied without its indent.
4. **Setext headings show their markers.** The `===` / `---` underline still shows; Notion doesn't use them.
5. **"+" has left the rows.** New page in a folder is only in the folder's context menu.
6. **Width is app-wide.** Sidebar width is one setting for the app, not per vault.
7. **Fields are 36 px,** the button height, not 40–44 px. The recorder bar's mic select is 28 px.
8. **Some fields keep their own look:** page title and subtitle, the rename field in a row, Search's query bar, the Settings menu search, and the toolbar's 30 px select.
9. **The Notion dialog has no close button,** like the other single-pane dialogs.
10. **Recent vaults show no page count.** Counting would walk every vault on each Welcome load. They show only "last opened".
11. **⌘N and ⌘O work on Welcome.** ⌘N picks a folder and creates a vault; ⌘O opens one.
12. **The Welcome filter appears from 6 vaults.**
13. **The ★ keeps one accessible name,** "X in Favorites", with `aria-pressed` for the state. The page-header star still uses the older changing-name pattern and is left for later.
14. **"File context menu" was read as the macOS File menu,** because the explorer's context menu has no quick-note item.
